# Ту-95МС / Ту-95МСМ

Оригинальная low-poly модель по предоставленным фотографиям: полётная
конфигурация с убранным шасси, серебристый фюзеляж, стреловидные крылья,
четыре мотогондолы и восемь четырёхлопастных соосных винтов.

Одна модель назначена через `sprite = rus_tu95` двум вариантам:
- `RUS_strat_bomber_equipment_tu95ms`
- `RUS_strat_bomber_equipment_tu95msm`

Ту-22М3 явно сохраняет `heavy_plane`, чтобы его ветка с Ту-160 не получила
новую модель через наследование от Ту-95МС. Характеристики техники не изменены.

Игровые файлы: `../../gfx/models/units/planes/tu95/`, регистрация —
`../../gfx/entities/rus_tu95.asset` и `rus_tu95.gfx`.
Исходники рядом: `tu95ms.obj`, `tu95ms.mtl`, `tu95ms_diffuse.png`.
OBJ — статическая редактируемая геометрия; риг и анимация воспроизводятся скриптом.
Оси: Y вверх, нос направлен по -Z, размеры в условных художественных единицах.

Исправленная версия: 19 344 треугольника, один материал, три DDS 512×512 с mip-цепочками.
Геометрия пересобрана в `refined_geometry.py`: плавные симметричные сечения
корпуса, отдельные изогнутые стёкла кабины, замкнутые профили крыла и киля,
обтекатели корней, стройные мотогондолы и объёмные скрученные лопасти.
Ступицы соосных винтов разнесены по оси; левая и правая половины зеркальны.
Девять костей: корпус и восемь винтов. Анимация — визуальный бесшовный цикл
со встречным вращением пар, а не физическая симуляция оборотов двигателя.

Пересоздание из корня мода (Python, NumPy, Pillow):
```
python tools/tu95/build_tu95.py
python tools/tu95/validate_tu95.py
```
Использует существующие инструменты `flamingo`, `shahed` и `model_export.py`.
Проверяются экспорт/повторное чтение mesh, бюджет полигонов, зеркальная симметрия,
индексы, нормали, UV, кости и кватернионы анимации, а также габариты на всём цикле
вращения винтов. `preview.png` и `views.png` отрисованы из игрового mesh.
В запущенной HOI4 модель пока не проверена. После добавления перезапустите игру
с включённым модом; отображение самолётов зависит также от настроек 3D-юнитов
и выполняемых авиамиссий.
