# Герань-5 — отдельная игровая модель

Создана по предоставленному изображению: тёмный длинный корпус, прямые
крылья, горизонтальное хвостовое оперение с двумя концевыми килями,
светлый двигатель сверху и нижний обтекатель. Пропорции визуальные,
в условных единицах; геометрия не предназначена для инженерного применения.

3 304 треугольника, 9 912 вершин, один материал и одна кость root.
DDS-карты diffuse/normal/specular — 512 × 512 с 10 mip-уровнями.
Статический исходник для редактора: geran5.obj, geran5.mtl и PNG-текстура.

Назначение: только `rus_guided_uav_geranium5`, sprite `rus_geran5`.
Самостоятельная entity содержит состояния idle, launch, move, bomb,
crash и explode. Движение задаёт игра; анимация хранит постоянную позу.
Предыдущая общая модель шахеда сохранена для остальных шести вариантов.
Характеристики оборудования и технологии не меняются.

Сборка из корня репозитория, Python 3 + NumPy + Pillow:

```powershell
python tools/geran5/build_geran5.py
python tools/geran5/render_geran5.py
python tools/validate_missile_models.py
```

Используются tools/model_export.py и геометрические примитивы/рендерер
из tools/flamingo. Проверены бинарный экспорт, полигоны, нормали,
тангенты, UV, текстуры, кость, анимационные привязки и назначение sprite.
preview.png и views.png — рендеры фактической игровой геометрии.
Запуск и полёт в HOI4 не проверены; для загрузки новых ассетов
нужен полный перезапуск игры.
