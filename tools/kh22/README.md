# Х-22 / Х-32
Отдельная внешняя игровая модель по предоставленным референсам.
4364 треугольника; Y вверх, нос -Z; условные художественные единицы.
Материалы и экспорт основаны на модели Х-55. Масштаб entity 0.60.
Привязана к rus_light_guided_missile_kh22 и rus_light_guided_missile_kh32.
Исходник: kh22.obj, kh22.mtl, kh22_diffuse.png.
Пересборка: python tools/kh22/build_kh22.py
Рендер экспортированного меша: python tools/kh22/render_kh22.py
Игровые файлы: gfx/models/units/missiles/kh22, gfx/entities/rus_kh22.asset и .gfx.
Проверены геометрия, UV, нормали, текстуры с mipmaps, анимационные состояния и обе привязки.
Непосредственная проверка полёта в HOI4 не проводилась.
