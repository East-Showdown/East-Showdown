# Герань-5К5-К

Отдельная игровая модель по трём изображениям пользователя: длинный тёмный
корпус с округлым носом, большие стреловидные плоскости, меньшие хвостовые,
боковые сервисные панели и короткое металлическое сопло с углублением.

Центральные стабилизаторы закреплены сверху корпуса и расположены строго
горизонтально: высота средней плоскости 0,420 при радиусе корпуса 0,435.
Задняя пара начинается немного выше, на высоте 0,455, и поднимается к концам
всего на 3°. Небольшие переходы у корней соединяют плоскости с верхней частью
корпуса без зазоров. Обратная сторона симметрична. Это художественная
интерпретация внешности в условных единицах, а не точная реконструкция изделия.
Наземные фотографии использованы для отделки, без повреждений и надписей.

- **3 424 треугольника**, 2 152 экспортированные вершины, одна кость `root`.
- Один объект, один материал, один связный замкнутый меш. Корни плоскостей
  встроены в сетку корпуса. Разделения вершин по UV и нормалям намеренные.
- Длина 10 условных единиц, нос направлен по −Z, верх по +Y. Entity scale 0.55.
- Общий атлас **1024 × 1024**: diffuse, normal и specular DDS, 11 mip-уровней.
- PNG для обычных редакторов: basecolor, normal, roughness, metallic.
- Basecolor без запечённого направленного света, теней и AO. Швы и небольшие
  детали выполнены текстурами; отдельной внутренней механики нет.

`geran5k5k.glb` — переносимый исходник с вложенными PBR-картами.
`geran5k5k.obj` + `geran5k5k.mtl` + четыре PNG — альтернативный исходник.
Импортируйте GLB или OBJ в редактор; они содержат ту же геометрию, что и .mesh.
Скрипты позволяют заново собрать модель без Blender и стороннего экспортёра.

Игровые файлы находятся в `gfx/models/units/missiles/geran5k5k/`.
Регистрация — `gfx/entities/rus_geran5k5k.asset` и `.gfx`.
Назначение: только `rus_guided_uav_geranium5k5_k`, sprite `rus_geran5k5k`.
Состояния idle/launch/move/bomb/crash/explode используют статическую позу;
перемещение объекта задаёт игра. Отдельных эффектов пламени или дыма нет.

Сборка из корня мода, Python 3 + NumPy + Pillow:

```powershell
python tools/geran5k5k/build_geran5k5k.py
python tools/geran5k5k/export_glb.py
python tools/geran5k5k/validate_geran5k5k.py
python tools/geran5k5k/render_geran5k5k.py
```

Проверка включает бинарный экспорт, UV, нормали и тангенты, замкнутость и
связность геометрии, симметрию плоскостей, реальную глубину сопла, материалы,
анимационные привязки, GLB и отсутствие посторонних изменений оборудования.
`baseline.json` хранит контрольные суммы прежних моделей и исходного equipment.

`preview.png`, `side.png`, `views.png`, `nozzle.png`, `rear_alignment.png` — программные рендеры
экспортированного .mesh с игровыми DDS. Это не скриншоты HOI4. Запуск в самой
игре не проверен; окончательный вид и масштаб нужно оценить после её полного
перезапуска с модом.
