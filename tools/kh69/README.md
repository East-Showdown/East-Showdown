# Х-69
Внешняя игровая модель по предоставленным изображениям: 1330 треугольников.
Y вверх, нос -Z, условные художественные единицы. Масштаб entity 0.60.
Привязка: rus_aircraft_guided_missile_equipment_kh69 → rus_kh69_entity.
Исходники: kh69.obj, kh69.mtl, kh69_diffuse.png.
Пересборка: python tools/kh69/build_kh69.py
Рендер: python tools/kh69/render_kh69.py
Проверены меш, UV, нормали, DDS с mipmaps, анимация и игровая привязка.
Проверка непосредственно в HOI4 не проводилась.
