# Орлан — общая игровая модель четырёх дронов
Внешняя модель по референсам пользователя, 1708 треугольников.
Назначена Гербере, БМ-35, Молнии и Молнии-2 по запросу пользователя.
Двухлопастный винт имеет отдельную кость и циклическую анимацию вращения.
Исходники: orlan.obj, orlan.mtl, orlan_diffuse.png.
Пересборка: python tools/orlan/build_orlan.py
Рендер: python tools/orlan/render_orlan.py
Игровые файлы: gfx/models/units/missiles/orlan и gfx/entities/rus_orlan.asset/.gfx.
Проверены меш, материалы, анимация и четыре привязки. Проверка в HOI4 не проводилась.
