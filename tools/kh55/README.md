# Х-55 — игровая модель

Модель создана по предоставленным пользователем изображениям: светлый
цилиндрический корпус, округлый нос, раскрытые крылья, три хвостовые
поверхности и двигатель под хвостовой частью. Геометрия декоративная,
в условных единицах; это не инженерная реконструкция.

3 556 треугольников, один материал, одна кость. Текстуры diffuse, normal
и specular — DDS 512 × 512 с полной цепочкой mip-уровней. OBJ и MTL
в этой папке являются статическим исходником для 3D-редактора.

`rus_kh55_entity` имеет собственные состояния и анимационные привязки.
Она не зависит от отсутствующей в моде `missile_default_entity`.
Модель назначена именно четырём типам со скрина:

- `rus_medium_guided_missile_kh55` — Х-55;
- `rus_medium_guided_missile_kh55cm` — Х-55СМ;
- `rus_medium_guided_missile_kh555` — Х-555;
- `rus_medium_guided_missile_kh101` — Х-101.

Общий внешний вид Х-55 используется для всей четвёрки по запросу
пользователя. Отдельная геометрия Х-101 не создавалась. Изменено только
поле sprite; характеристики, технологии и Х-101М не менялись.

Сборка из корня репозитория, Python 3 + NumPy + Pillow:

```powershell
python tools/kh55/build_kh55.py
python tools/kh55/render_kh55.py
python tools/validate_missile_models.py
```

Используются существующие примитивы, бинарный ввод-вывод и рендерер
из `tools/flamingo`. Рендерер расширен параметром пути к модели.
`preview.png` и `views.png` показывают экспортированную геометрию,
а не запущенную HOI4. Полёт в самой игре пока не проверен; после
добавления ассетов нужен полный перезапуск игры.
