# Шахед-136 / Герань-2 — игровая модель

Новая модель по изображению пользователя: светлый центральный корпус,
синяя полоса, треугольные крылья, концевые кили и задний винт.
Все размеры условные и служат визуальному сходству.

2 736 треугольников, один материал, две кости: root и propeller.
Винт получает отдельную циклическую анимацию. DDS-текстуры — 512 × 512,
с 10 mip-уровнями. Статический исходник: shahed136.obj + MTL + PNG.

Самостоятельная `rus_shahed_entity` назначена основной ветке:
Шахед-131, Герань-1, Герань-2, Герань-2М, Герань-3.
Герань-4 использует отдельную модель из tools/geran4.
Герань-5 использует отдельную модель из tools/geran5.
Одна общая модель используется по запросу пользователя, включая поздние
модификации с отличающейся реальной компоновкой. Боковые технологии
«Гербера» и БМ-35 сохраняют прежние модели. Характеристики не изменены.

```powershell
python tools/shahed/build_shahed.py
python tools/shahed/render_shahed.py
python tools/validate_missile_models.py
```

Нужны Python 3, NumPy, Pillow и общие инструменты из tools/flamingo.
Предпросмотры показывают экспортированную геометрию. Проверка включает
скелет, вращение винта вокруг собственной оси, текстуры и игровые ссылки.
В самой HOI4 полёт не проверен. Для загрузки новых моделей перезапустите игру.
