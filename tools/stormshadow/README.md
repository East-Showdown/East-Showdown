# Storm Shadow
Внешняя игровая модель по предоставленным референсам. 5022 треугольника.
Привязка: nto_light_guided_missile_equipment_shtormshadow → nto_stormshadow_entity.
Исходники: stormshadow.obj, stormshadow.mtl, stormshadow_diffuse.png.
Пересборка: python tools/stormshadow/build_stormshadow.py
Рендер: python tools/stormshadow/render_stormshadow.py
Экспорт: gfx/models/units/missiles/stormshadow.
Проверены геометрия, UV, материалы, анимационные состояния и игровая привязка.
Проверка непосредственно в HOI4 не проводилась.

Обновление качества: плавные нормали корпуса, более точный нос, профилированные крылья и оперение, маркировка.

Хвост исправлен по дополнительному фото: боковые стабилизаторы и парные наклонные поверхности.
