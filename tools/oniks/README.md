# П-800 «Оникс» — белая модель

Подготовлена из пользовательского архива `P800 Oniks Brahmos High Poly.zip`.
Белая окраска без надписей; 6 400 треугольников, 19 200 экспортных вершин.
Один материал `PdxMeshAdvanced`, DDS 64×64 с семью mip-уровнями.

## Привязка

- Оборудование: `rus_medium_guided_missile_oniks`.
- Исследование: существующая технология `missile_rus_3M55`.
- В оборудовании: `sprite = rus_oniks`.
- Entity: `rus_oniks_entity`; pdxmesh: `rus_oniks_mesh`.
- Ресурсы: `gfx/models/units/missiles/oniks/`.
- Регистрация: `gfx/entities/rus_oniks.asset` и `rus_oniks.gfx`.

Длина меша — около 10 условных единиц, Y вверх, нос −Z.
Масштаб entity — 0.55. Анимация задаёт статическую позу; отдельного движения
рулей и эффекта запуска нет. Состояния используют ту же схему, что другие ракеты мода.

## Исходник и проверка

`source/oniks_white.blend` — редактируемая модель, Z вверх, нос +Y.
`source/oniks_white.glb` — переносимая копия с материалом.
При последующих ручных изменениях экспортируйте именно изменённый `.blend`.

`validate.py` проверяет установленный mesh, DDS, анимацию, GLB,
назначение существующему оборудованию и уникальность регистраций.
Требуется обычный Python 3 без внешних библиотек; используется
`../flamingo/pdx_io.py` из этого мода.

```text
python tools/oniks/validate.py
```

Геометрия экспортированного меша ранее просмотрена с четырёх ракурсов.
Проверки файлов и привязок выполнены при установке; HOI4 не запускалась.
Размер и отображение игрового материала требуют проверки в самой игре.
