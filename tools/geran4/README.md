# Герань-4

Отдельная игровая модель по предоставленному референсу: тёмный корпус,
треугольное крыло, концевые кили, светлый задний блок и приглушённые панели.
1556 треугольников, общий материал, DDS 512×512 с mip-цепочками.
Y вверх, нос по -Z, условные художественные единицы.

Назначена только `rus_guided_uav_geranium4` через `sprite = rus_geran4`.
Игровые файлы в `gfx/models/units/missiles/geran4`, определения в
`gfx/entities/rus_geran4.asset` и `.gfx`. Характеристики техники не изменены.
OBJ, MTL, PNG, генератор и предпросмотры находятся рядом с этим документом.

Сборка из корня: `python tools/geran4/build_geran4.py` (NumPy, Pillow).
Проверка: `python tools/validate_missile_models.py`.
В игре не проверено; после добавления перезапустите HOI4 с включённым модом.
