# Х-47М2 «Кинжал» — модель для HOI4

Самостоятельная внешняя 3D-модель по пяти предоставленным изображениям.
Подключена к существующему `rus_medium_guided_missile_kh47m2` через
`sprite = rus_kinzhal`. Технология `missile_rus_kh47`, локализация и стартовые
запасы России уже присутствуют в моде. Характеристики вооружения не изменены.

## Содержимое

- 10 084 треугольника, 6 104 индексированных вершины, один материал.
- Y вверх, нос вдоль -Z, центр габаритов в начале координат; длина 10 условных
  художественных единиц, игровой масштаб entity — 0.60.
- Длинная головная часть, четыре больших и четыре малых хвостовых плоскости,
  две наружные направляющие, крепёжные скобы.
- Плавно сужающийся хвост; малые плоскости развёрнуты на 45° относительно
  большого ряда, их основания подогнаны к хвостовой обшивке без зазоров.
- Компактное открытое сопло с тонкой кольцевой кромкой и тёмным углублением.
  Внутренние механизмы не моделируются.
- UV-развёртка корпуса; одинаковые небольшие симметричные детали используют
  общие участки атласа. Швы и заклёпки представлены текстурой и normal map.
- Три игровые DDS-текстуры 1024×1024, каждая с 11 mip-уровнями.
- `kinzhal.obj` / `kinzhal.mtl` и PNG Base Color, Roughness, Metallic,
  tangent-space Normal для редактирования. В программах без поддержки PBR MTL
  подключите карты roughness, metallic и normal вручную.
- `kinzhal_normal.png` — стандартная RGB normal map. Игровая DDS содержит
  упакованные X в alpha и Y в green, как в других моделях мода.
- Независимые состояния idle, launch, move, bomb, crash, explode с постоянной
  pose-анимацией. Перемещение управляется движком игры. Отдельного LOD нет.

## Пересборка

Требуются Python 3, NumPy, Pillow. Из корня мода:

```powershell
python tools/kinzhal/build_kinzhal.py
python tools/kinzhal/validate_kinzhal.py
python tools/kinzhal/render_kinzhal.py
```

Игровые файлы: `gfx/models/units/missiles/kinzhal/`,
`gfx/entities/rus_kinzhal.asset`, `gfx/entities/rus_kinzhal.gfx`.
`preview.png`, `rear.png`, `views.png` и `tail_detail.png` показывают экспортированный `.mesh`
с его DDS-текстурами в приближённом освещении, а не скриншот из HOI4.

Проверяются геометрия, UV, направления граней, нормали и тангенты, отсутствие
дублированных граней, симметрия оперения, открытое сопло, материалы, mipmaps,
анимационные ссылки и единственная привязка к вооружению.
Текущая правка по уточнённому заданию затрагивает сужение хвостовой части,
сопло и ориентацию/основания малых стабилизаторов. По `tail_rework_baseline.json`
проверяется точное сохранение 7 200 треугольников носа и передней части,
координат и UV основного корпуса до начала сужения, больших плоскостей,
скоб, направляющих, текстур и игровых привязок. Сглаживание обновлено только
у перехода к новому хвосту. `rear_edit_baseline.json` хранит контрольные суммы
более ранней правки одного сопла и не задаёт ограничения текущей ревизии.
Проверка непосредственно в запущенной HOI4 не проводилась.
Для проверки в игре перезапустите HOI4 с модом, выберите Россию и используйте
Х-47М2 «Кинжал»: новая модель относится к этой ракете.

## Визуальные источники

Все пять приложенных пользователем изображений от 28.10.2026:
`12_25_14.webp` (два общих ракурса), `12_25_06.webp` (задний ракурс),
`12_25_28.webp` (силуэт и сетка), `12_25_24.jpg` (вид сбоку),
`12_25_20.webp` (ракурс с направляющей). Изображения служат референсами;
геометрия и текстуры создаются генератором, изображения не встраиваются в мод.
Из читаемых надписей воспроизведено только «БАНДАЖ».
Для уточнения хвоста использован дополнительный крупный задний ракурс
`codex-clipboard-2e08aff2-49ac-4314-8d30-be9f4d058217.png` и приложенное задание
на сужение хвоста, компактное открытое сопло и разнесённые углы стабилизаторов.
